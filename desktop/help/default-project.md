# Set Default Project

Chooses which of the open projects is the default project. Choose `Project > Set Default Project...`. The command is available only when more than one project is open.

## What is on it
- **Project ID** and **Project**: each open project, by short code and name.
- **Default**: a check mark on the project that is the default now. Click a row to move the check to it.
- **OK**: makes the checked project the default.
- **Cancel**: closes the window and leaves the default as it was.
- **Help**: opens this topic.

## What the default project does
- New activities you add go into the default project. OpenXER switches to it first.
- With several projects open, the Schedule dialog (`F9`) uses the scheduling options of the default project.
- `File > Close All` closes every open project except the default one.
- The status bar shows "Default Project:" and its ID while several projects are open.

## Common tasks
1. Open two or more projects with `File > Open...`.
2. Choose `Project > Set Default Project...`.
3. Click the row of the project that should get new activities.
4. Click **OK**.

## Good to know
> When the default project is closed, the active project becomes the default.
> The choice is kept with the open set, so it is still there next time the same projects open.
