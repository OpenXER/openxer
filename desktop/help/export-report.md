# Export Report

Export Report saves one report's definition (its layout and settings, not its results) to a file, so you can back it up or share it with another OpenXER user. Open it from the Reports view: select a report, right-click and choose **Export...**, or click the Export Report button on the Reports toolbar.

## What is on it
- **Report**: the name of the report you are exporting.
- **File**: the path of the definition file. It starts as the report's name with the .rpt extension in your Documents folder. The **...** button picks another place with a save box.
- **OK**: writes the file and closes the dialog. It stays disabled while **File** is empty.
- **Cancel**: closes without writing anything.
- **Help**: opens this topic.

## Common tasks
1. Select the report in the Reports view and choose **Export...**.
2. Check the **File** path, or click **...** to choose another.
3. Click **OK**. The status bar says where the file went.

## Good to know
> Export works only for definition reports: those built in the Report Editor, imported, or supplied with OpenXER. For reports made with the Report Wizard, the command is unavailable.
> When you click **OK**, an existing file at that path is replaced without asking.
> To save a report's results instead, use `Run > Report to File...`.
