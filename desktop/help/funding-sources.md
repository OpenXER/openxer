# Funding Sources

Funding sources are the budgets or accounts that pay for a project, kept as a tree. Open this dialog with `Enterprise > Funding Sources...`, or with the Funding Sources button on the Dictionaries toolbar.

## What is on it
- **Funding Source** list: the tree of sources. Click the name of the selected row to rename it in place. Names must be unique among sources at the same level.
- **Notes** area: a **Description** box for the selected source, up to 4000 characters.
- **Close**, **Add** (adds under the selected source), **Delete**, **Cut**, **Copy**, **Paste** (pastes under the selected source), the **arrow pad** (up and down reorder; right indents; left outdents) and **Help**.
- Right-click a row for Add, Delete, Cut, Copy and Paste.

## Common tasks
1. Select the parent source and click **Add**.
2. Type the name, then add a **Description**.

## Good to know
> Deleting a source also deletes the sources under it, after you confirm. Project funding rows that name any of them are deleted too.
> The tree can be at most 10 levels deep.
