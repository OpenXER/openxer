# Issue Navigator

The Issue Navigator lists the open project's issues in a small window you can keep beside your work, and takes you straight to the activity or WBS element each issue is about. An issue is a problem you want tracked to a fix, raised by hand in the Issues view or by Monitor Thresholds. Open it with `Tools > Issue Navigator...`.

## What is on it
- **Project Issues** list: every issue with its **Issue** name, **Priority**, **Status**, **Activity ID** and **WBS**. Click a row to select it.
- **Close**: closes the window.
- **Help**: opens this topic.
- **Activities**: shows the Activities view with the issue's activity selected. Enabled when the issue is about an activity.
- **WBS**: shows the WBS view with the issue's WBS element selected, or the WBS element of the issue's activity.
- **Issue Details**: shows the Issues view with this issue selected and its details open. Double-clicking an issue does the same.
- **Resources**, **Tracking** and **Notify** are shown but not available.

## Common tasks
1. Run `Tools > Monitor Thresholds...` to raise issues, or add them in the Issues view.
2. Open the Issue Navigator and click an issue.
3. Click **Activities** to go to the activity and fix the problem.
4. Click **Issue Details** to record the resolution and close the issue.

## Good to know
> The navigator lists all issues, open and closed. Use the Issues view to filter them.
> The window stays open while you work in the views, so you can step through the issues one by one.
