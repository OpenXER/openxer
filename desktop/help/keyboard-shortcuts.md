# Keyboard shortcuts

The keys below work in the main window. While a dialog is open the main window's
keys wait, so a key never acts on the project behind a dialog.

## Help
- `F1`: help for the dialog in front, or for the current view.
- `Ctrl+F1`: the help contents.
- `Alt+F1`: turn Cell Tips (hover text on table cells) on or off.

## Files
- `Ctrl+N`: new project. `Ctrl+O`: open a project. `Ctrl+W`: close every open
  project except the default project.
- `Ctrl+S` or `F10`: save to the workspace.
- `Ctrl+P`: print. `F5`: refresh the view.

## Editing activities
- `Insert`: add an activity. `Delete`: delete the selected activities, after you
  confirm. In the Expenses, Documents, Risks, Issues and Thresholds views the
  same keys add and delete a row.
- `F2`: edit the selected cell.
- `Ctrl+Z` and `Ctrl+Y`: undo and redo.
- `Ctrl+F`: find. `F3`: find the next match. `Ctrl+H` or `Ctrl+R`: replace.
- `Ctrl+E`: fill down: copies the first selected activity's value in the current
  column into the other selected activities.

## Scheduling
- `F9`: open the Schedule dialog.
- `Shift+F9`: open Level Resources.

## AI agents
- `F8`: open or close [Chat](ai-chat). In Chat, `Enter` sends and `Shift+Enter`
  starts a new line.

## Moving around
- Arrow keys, `Page Up`, `Page Down`, `Home` and `End` move through the table.
- `Ctrl+Tab` and `Ctrl+Shift+Tab` switch between open view tabs. `Ctrl+F4` closes
  the current tab.
- Press and release `Alt` to reach the menu bar, or press `Alt` with the
  underlined letter of a menu to open it.
- `Shift+F10` or the Menu key opens the right-click menu of the focused view.

## In dialogs
- `Enter` runs the dialog's default button. `Escape` closes the dialog without
  changes.
- `Alt` with an underlined letter presses that button.
