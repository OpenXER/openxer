# New Layout

Makes a new named layout and switches to it. A layout is a saved set of view settings for the activity table and Gantt chart: columns, filters, grouping, bars and fonts. Choose `View > Layout > New Layout...`.

## What is on it
- **Layout Name**: the name of the new layout. It starts as "New Layout". It must not be empty, must not be longer than 100 characters, and must not match a layout that already exists (capitals do not count as a difference).
- **Start from the default layout**: the new layout begins with the standard columns, filters, grouping and Gantt chart settings. This is chosen when the window opens.
- **Start from the current layout**: the new layout is a copy of what you see now, with all its changes.
- **OK**: creates the layout, saves it and makes it the one in use.
- **Cancel**: closes without making a layout.
- **Help**: opens this topic.

## Common tasks
1. Choose `View > Layout > New Layout...`.
2. Type a name, for example "Piping by area".
3. Pick **Start from the current layout** to keep your present columns and filters, or **Start from the default layout** for a clean start.
4. Click **OK**, then change columns, filters or grouping as needed.
5. Choose `View > Layout > Save Layout` to keep later changes.

## Good to know
> If the name is taken, an error says so and nothing is created.
> Starting from the current layout works like **Save Layout As**: the copy is saved under the new name right away.
> Starting from the default layout does not ask about unsaved changes to the layout you were on. Save it first if you want to keep them.
> Layouts are kept in the workspace, so they are there for every project you open.
