# Welcome to OpenXER Help

OpenXER is a desktop scheduler for construction and project work. It reads and
writes XER files, calculates the schedule with the critical path method, and keeps
your work in a local workspace on this PC. Nothing in this help needs a network
connection.

## Where to start
- [Getting started](getting-started): open or import a project, find your way
  around the main window, save and export.
- [Scheduling basics in OpenXER](scheduling-basics): the data date, `F9`,
  constraints, actual dates, leveling and baselines.
- [Keyboard shortcuts](keyboard-shortcuts): the keys worth learning first.
- [Working with AI agents](working-with-ai-agents): let an AI assistant read and
  update your schedule files.

## Getting help while you work
- Press `F1` in any dialog to open the topic for that dialog. With no dialog open,
  `F1` opens the topic for the view you are in.
- Every dialog's **Help** button opens the same topic as `F1`.
- `Ctrl+F1` or `Help > Help Topics...` opens this page.

## Using this window
- The list at the left is the table of contents. Click a topic to read it.
- Type in **Search** to list every topic that holds all of your words. Clear the
  box to get the contents back.
- Blue words are links to other topics. **Back** and **Forward** (or `Alt+Left`
  and `Alt+Right`) step through the topics you have read.
- **Contents** comes back to this page. **Close** or `Escape` closes the window;
  the dialog you were in stays open.
- The window opens beside the dialog it explains. Drag its title bar to move it,
  and the grip in its bottom-right corner to make it larger. Drag across topic
  text to select it, then press `Ctrl+C` to copy it.
