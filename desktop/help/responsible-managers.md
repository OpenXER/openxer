# Responsible Managers (OBS)

The OBS (organizational breakdown structure) is a tree of the people or groups responsible for parts of the work. WBS elements, issues and thresholds name an OBS element as responsible. Open it with `Enterprise > Responsible Managers (OBS)...`.

## What is on it
- **OBS Name** list: the tree of elements. Click a cell of the selected row to rename it in place; Enter keeps the change, Escape drops it. Names must be unique among elements at the same level.
- **General** area under the list, for the selected element:
- **OBS Name**: the same name, as a text box.
- **Description**: free notes about the element, up to 4000 characters.
- A line that counts the WBS, issue and threshold records this element is responsible for.
- **Close**, **Add** (adds under the selected element), **Delete**, **Cut**, **Copy**, **Paste** (pastes under the selected element), the **arrow pad** (up and down reorder; right indents under the element above; left outdents) and **Help**.
- Right-click a row for Add, Delete, Cut, Copy and Paste.

## Common tasks
1. Select the parent element and click **Add**.
2. Type the name in **OBS Name** and add a **Description**.
3. Use the arrow pad to adjust where it sits.

## Good to know
> Deleting an element also deletes the elements under it, after you confirm. Records that named any of them as responsible pass to the element named in the question: the deleted element's parent, or another top element.
> The OBS must keep at least one element, and it can be at most 10 levels deep.
> The OBS is part of the project data, so it is saved with the project and written to XER files.
