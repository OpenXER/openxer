# Revert Project to Baseline

Rolls the open project back to one of its baselines: the project's activities, relationships, assignments and other data are replaced by the baseline's. Open it with `Project > Revert Project to Baseline...`.

## What is on it
- **The baseline list**: the open project's baselines, with **Baseline ID**, **Baseline Name** and **Data Date**. Click one to select it.
- **Revert**: asks first, then replaces the project's data with the selected baseline's.
- **Close**: closes without changes.

## Good to know
> The project keeps its own Project ID, name, project baseline and its other baselines. The baseline itself is not changed and stays in [Maintain Baselines](maintain-baselines).
> This is not the **Restore** button of Maintain Baselines: Restore turns a baseline into a separate project and takes it out of the baseline list.
> Reverting is one undo step: `Ctrl+Z` brings the project back as it was.
