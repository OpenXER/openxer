# Table, Font and Row

Sets the font, cell color and row height of the activity table. Choose `View > Table Font and Row...`, or right-click the table and choose **Table Font and Row...**.

## What is on it
- **Font**: the sample button shows the current font. Click it to open the **Font** window and choose the **Font**, **Font style** (Regular, Italic, Bold or Bold Italic), **Size** (6 to 20) and **Color**. A **Sample** shows how text will look.
- **Color**: the background color of the table cells. Click the swatch to pick a color.
- **Keep Current Row Heights**: leaves the row height as it is. It is ticked each time the window opens. Clear it to use the two choices below.
- **Optimize height by row content**: each row grows to fit long text that wraps. **Do not exceed** with a number of **lines per row** stops a row growing past that many lines (1 to 20).
- **Select height for all rows**: one fixed height for every row, from 17 to 48. Another value is refused when you click **OK** or **Apply**, and the window says why beside the field.
- **Show Icons**: shows the small activity type icons in the first column of the table.
- **OK**: applies the settings and closes. **Apply** applies and stays open. **Cancel** closes and changes nothing.
- **Default**: puts back the standard font, color and icons, clears **Keep Current Row Heights** and sets the standard fixed row height. Click OK or Apply to use them.
- **Help**: opens this topic.

## Common tasks
1. Choose `View > Table Font and Row...`.
2. Click the **Font** sample, pick a larger **Size** and click **OK**.
3. Clear **Keep Current Row Heights** and choose **Optimize height by row content** so long activity names wrap.
4. Tick **Do not exceed** and set 3 lines per row.
5. Click **OK**.

## Good to know
> Rows in the table and bars in the Gantt chart line up, so a taller row also spaces the bars further apart. **Select height for all rows** sets the same row height as **Row height** in [Bar Chart Options](bar-chart-options).
> A row is never shorter than its font needs, whatever height you set.
> The font, color, icon and row settings belong to the current layout. They are kept in the named layout when you save it with `View > Layout > Save Layout`.
