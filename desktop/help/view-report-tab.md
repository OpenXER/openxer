# Report

When you run a report to the screen, it opens in its own tab beside the other views, named after the report. You choose where it goes next (a file or the printer) from the tab itself. Run a report from the Reports view (`Tools > Reports > Reports`) or the Report Wizard.

## What it shows
- **Header line**: the report name, the project, its data date (the date progress is measured up to), when the report was run and how many pages it has.
- **Viewer**: the report's pages. The toolbar has **Pages** (a strip of page thumbnails), **Find**, **Zoom Out**, a zoom choice with **Fit Width** and **Fit Page**, **Zoom In**, **Zoom to Fit**, buttons to move between pages and a **Page** box to jump to one.
- **Export**: a menu of file types: **PDF...**, **Excel (.xlsx)...**, **HTML...**, **Text (ASCII)...** and **CSV...**.
- **Print**: sends the report to a printer.
- **Refresh**: runs the report again on the current data.
- **Status line**: the page, the zoom, and after an export the file name with **Open** and **Open Folder** links.

## Common tasks
1. Read through the pages, using **Find** to look for a word or an ID.
2. Click **Export** and pick a file type. Choose where to save the file.
3. Click **Open** on the status line to look at the file, or **Open Folder** to find it.
4. After you change the schedule, click **Refresh** (or press `F5`) to bring the report up to date.

## Good to know
> **CSV...** is only offered for reports laid out as a table.
> **Text (ASCII)...** first asks for the field delimiter and the text qualifier (the character put around each value).
> `Ctrl+C` copies the text of the whole report, or only the current page while the **Pages** strip is open.
> Report tabs are not saved with your layout. Closing the tab, or the program, frees the report; run it again to get it back.
> Right-click the tab for **Close**, **Close Other Report Tabs**, **Close All Report Tabs** and the tab group commands, to view a report beside the schedule.
